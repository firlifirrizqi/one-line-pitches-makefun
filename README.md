## The pitch

> You don't need to learn to code first - tell an AI agent your app idea in plain words on make.fun and it will build a working first version for you, so the idea you've been carrying around finally becomes something you can tap and share.

## How it works

`main.py` writes that single sentence to `/output/entry.txt` (1–240 characters, UTF-8, one line).

```sh
python3 main.py
cat /output/entry.txt
```
